# Flanker over LAX

Browser jet combat game (Three.js). Open the GitHub Pages link, take off, start missions. Co-op: one player hosts a room, friends join with the 5-letter code.

Controls: Xbox controller (RT gas, LT brake, B boost, A drift, X fire, Y weapon, D-pad targets/flares, R3 zoom) or mouse + keyboard (mouse aim, W/S gas/brake, Space boost, F fire).
